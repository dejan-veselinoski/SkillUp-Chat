─── MANUAL DEPLOYMENT (without Claude Code) ──────────────────
If you prefer to do it yourself:

1. Copy your files to the server:
   scp -r ./my-app root@37.60.249.140:/opt/my-app

2. SSH in and set up:
   ssh root@37.60.249.140
   cd /opt/my-app
   npm install
   echo "PORT=5000" > .env

3. Start with PM2:
   pm2 start server.js --name my-app
   pm2 save
   pm2 startup   (run the printed command to auto-start on reboot)

4. Open the firewall port:
   ufw allow 5000

5. Test it:
   curl http://localhost:5000/health


─── USEFUL PM2 COMMANDS ──────────────────────────────────────

  pm2 delete my-app         — remove from PM2
