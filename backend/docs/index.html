SkillUp Chat API

REST API for the group chat app. Register, send messages, share photos, and react with emoji — no WebSocket needed.

Live at 37.60.249.140:3001
JSON responses
JWT auth
Getting started

Authentication

Protected endpoints require a Bearer token in the Authorization header. Tokens are obtained from /auth/register or /auth/login and are valid for 30 days.

Header format
Authorization: Bearer <your_token>
Note: Every endpoint except GET /health, POST /auth/register, and POST /auth/login requires a valid token.

Messages

    
GET /messages

    
Fetch all messages with their reactions. Poll this endpoint every 2–3 seconds to keep the chat in sync. Reactions on existing messages are always included, so a full fetch is the simplest and most correct approach.


    

      GET
      /messages
    


    
Query parameters

    

      

        
ParamTypeDefaultDescription

        
          
sinceintegernoneReturn only messages with id greater than this value. Useful for optimization — omit it to always get the full history (recommended for correct reaction sync).

          
limitinteger100Maximum number of messages to return.

        
      

    


    
Response 200

    

      

        

        
      

    


    
Message object fields

    

      

        
FieldTypeDescription

        
          
idintegerUnique message ID

          
contentstring | nullMessage text, or photo caption (can be null)

          
type"text" | "photo"Message type

          
photo_urlstring | nullRelative path to photo (e.g. /uploads/file.jpg). Prepend the base URL to get the full link.

          
created_atstringISO-like datetime (UTC)

          
user.idintegerSender's user ID

          
user.full_namestringSender's full name

          
reactionsarrayList of reaction objects: { emoji, user_id, full_name }

Polling pattern

    
The API uses polling — no WebSocket needed. Call GET /messages every 2–3 seconds. Because reactions on old messages must also be reflected, always fetch the full list rather than using the since parameter.

CodeMeaning

404Not found — user or message doesn't exist

          
409Conflict — e.g. username already taken
